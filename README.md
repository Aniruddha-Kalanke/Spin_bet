# Spin_bet - Python Slot Machine

A text-based slot machine game built in Python.

## Features
- Deposit system with validation
- Choose 1-3 lines to bet on
- Random slot machine spin (3x3 grid)
- Win detection and payout calculation
- Balance tracking

## How to Run
```bash
python3 main.py
```
